# مركز عدن الدولي للسلامة والدراسات الميدانية (AICSFA)
## Aden International Center for Safety and Field Assessments
### Official Digital Corporate Platform & Portals Ecosystem

---

**«دعم سلامة العاملين في المجال الإنساني وتعزيز الوصول الآمن»**  
*Supporting Humanitarian Safety & Enabling Secure Field Access*

منظومة مؤسسية متكاملة لتقييم المخاطر الميدانية، التدريب المتخصص على السلامة (HEAT) وإدارة الأزمات، والمسوحات والأبحاث الميدانية الإنسانية الموثوقة.

---

## 1. نبذة عن المنصة (Platform Overview)
المنصة الرقمية الرسمية لـ **مركز عدن الدولي للسلامة والدراسات الميدانية (AICSFA)** هي نظام تشغيلي متكامل صُمم لخدمة المنظمات الدولية والمحلية العاملة في الميدان الإنساني والتنموي، ويشتمل على:

1. **الموقع المؤسسي العام (Public Portal):**
   - واجهة متعددة اللغات (العربية RTL والإنجليزية LTR بالكامل).
   - استعراض رسالة المركز ومجالات العمل الأساسية (تقييم المخاطر الميدانية، التدريب وبناء القدرات، الأبحاث الميدانية، والتحليل الميداني المستمر).
   - صفحة التحقق الرقمي الفوري من الشهادات عبر الرابط المباشر `/verify` ومطابقة رموز الاعتماد.
2. **بوابة العملاء والمنظمات الشريكة (`/portal/client`):**
   - تقديم ومتابعة طلبات تقييم المقرات والمسارات الميدانية بنظام التتبع المرجعي.
   - الاطلاع على التحديثات الميدانية واستلام تقارير التقييم النهائي المعتمدة بصيغة PDF.
3. **بوابة التنسيق الميداني (`/portal/field/intake`):**
   - واجهة مخصصة لمنسقي الاتصال الميداني (`FIELD_FOCAL_POINT`) لتسجيل البلاغات ورصد مستجدات التحرك الميداني وتغذية سجل الوقائع.
4. **بوابة المتدربين (`/portal/trainee`):**
   - متابعة الدورات التدريبية الميدانية (مثل HEAT والإسعافات الأولية للطوارئ)، وسجلات الحضور، وعرض وتنزيل الشهادات الصادرة.
5. **لوحة الإدارة والتحكم الشاملة (`/admin`):**
   - إدارة طلبات التقييم الميداني والخدمات.
   - إدارة الدورات والشهادات والتحقق والاعتماد.
   - نشر وإدارة الأبحاث والتقارير الميدانية والمقالات الإخبارية.
   - إدارة المستخدمين والصلاحيات والتحكم الإداري وسجلات التدقيق الرقابي (`Activity Logs`).

## 2. المعمارية والتقنيات البرمجية (Technology Stack)
- **الإطار البرمجي الأساسي:** Next.js 14+ (App Router, React 18, TypeScript).
- **قاعدة البيانات ونمذجة البيانات:** PostgreSQL مدعومة بمكتبة Prisma ORM.
- **الهوية البصرية والتصميم:** Vanilla CSS بتصميم مؤسسي متقن، مستوحى من الهوية المعتمدة، مع دعم Glassmorphism ودعم كامل للاتجاهين (RTL/LTR).
- **الأمان والتحقق من الهوية:** مصادقة محلية مشفرة بكلمات مرور `bcryptjs` وجلسات JWT عبر ملفات تعريف ارتباط آمنة (`httpOnly cookies`)، مع نظام صلاحيات صارم متعدد الأدوار (RBAC).
- **التخزين ونظام الإشعارات:** استخدام نظام التخزين المحلي الآمن ومحرك الإشعارات الداخلي، دون افتراض مفاتيح سحابية خارجية في هذه المرحلة.

## 4. خطوات التثبيت والتشغيل المحلي (Setup & Run)

### 1. تثبيت الاعتماديات (Dependencies)
```bash
npm install --legacy-peer-deps
```

### 2. إعداد ملف البيئة (.env)
انسخ ملف الإعدادات الافتراضي:
- في Windows PowerShell:
  ```powershell
  Copy-Item .env.example .env
  ```
- في Linux / macOS:
  ```bash
  cp .env.example .env
  ```

عدّل رابط قاعدة البيانات في ملف `.env` ليتطابق مع إعدادات PostgreSQL المحلية:
```env
DATABASE_URL="postgresql://postgres:YOUR_PASSWORD@localhost:5432/facss_db?schema=public"
APP_URL="http://localhost:3000"
AUTH_SECRET="your-secure-random-secret-key-at-least-32-chars-long"
```

### 3. تطبيق مخطط قاعدة البيانات (Prisma DB Sync)
```bash
npx prisma db push
```

### 4. تغذية البيانات الافتراضية (Seed Data — للتطوير الأولي فقط)
```bash
node scripts/seed.js
```
> **تنبيه:** لا تُشغّل سكربت التغذية على قاعدة بيانات تشغيلية أو تحتوي على بيانات حية للعملاء، حفاظاً على سلامة السجلات التاريخية.

### 5. تشغيل المنصة في بيئة التطوير
```bash
npm run dev
```
افتح المتصفح على: **`http://localhost:3000`**

### 6. بناء حزمة الإنتاج وتشغيلها
```bash
npm run build
npm start
```

## 5. الأدوار التشغيلية وبيانات الحسابات التجريبية (Roles & Demo Access)
تتضمن المنصة أدواراً مهنية مفصلة تلبي متطلبات المركز:
- **SUPER_ADMIN / ADMIN (الإدارة العليا):** إدارة شاملة للنظام والمستخدمين والإعدادات (`admin@facss-aden.com`).
- **SERVICE_MANAGER (مدير العمليات الميدانية):** متابعة طلبات التقييم الميداني وإسناد المهام وإرفاق التقارير النهائية (`services@facss-aden.com`).
- **FIELD_FOCAL_POINT (منسق الاتصال الميداني):** تسجيل وتغذية الوقائع الميدانية عبر `/portal/field/intake` (`field.focal@facss-aden.com`).
- **TRAINING_MANAGER (مدير قطاع التدريب):** جدولة الدورات الميدانية وإصدار الشهادات واعتمادها (`training@facss-aden.com`).
- **RESEARCH_MANAGER (رئيس وحدة الأبحاث):** إدارة ونشر الدراسات والتقارير الميدانية (`research@facss-aden.com`).
- **CLIENT (المنظمات الشريكة):** تقديم طلبات التقييم واستلام التقارير المعتمدة (`safety.officer@humanitarian-ngo.org`).
- **TRAINEE (المتدربون):** استعراض الدورات الميدانية وسجل الحضور والشهادات (`trainee@facss-aden.com`).

## 6. التحقق من الشهادات (Certificate Verification)
- يتيح الرابط العام المباشر **`/verify`** إدخال رمز التحقق للشهادات الصادرة والتأكد الفوري من صحتها وحالتها وسجل المتدرب.
- مسار التحقق البرمجي: `/verify/[code]` مع فحص موحد يمنع تزوير الشهادات ويوفر بيانات الاعتماد الرسمية.
