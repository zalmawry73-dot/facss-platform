# Client Portal User Guide

---

## 1. Portal Overview
The Client Portal (`/portal/client`) empowers contracted corporations, banks, government bodies, and international NGOs to monitor security operations with total transparency.

---

## 2. Key Capabilities
- **Overview Dashboard:** Instant metrics displaying active security requests, completed deployments, available reports, and operational notifications.
- **Service Requests Tracking:** Complete list of historical and active tickets. Click on any ticket to view:
  - Real-time 6-stage visual pipeline (`NEW` -> `UNDER_REVIEW` -> `APPROVED` -> `IN_PROGRESS` -> `REPORT_READY` -> `COMPLETED`).
  - Assigned security operations officer and contact.
  - Operations room progress notes thread.
  - Attached final deliverable reports.
- **Confidential Document Repository:** Access audited physical security assessments, vulnerability heatmaps, and periodic intelligence reports restricted exclusively to certified clients.
- **Corporate Profile:** Verify representative information and security credentials.
